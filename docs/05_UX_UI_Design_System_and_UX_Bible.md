# 05. UX/UI Design System & UX Bible — VeriField Nexus



## 1. Executive Summary

Canonical guide for design tokens, component standards, glassmorphic dark mode themes, and accessibility compliance.



## 2. Design System Tokens

- **Brand Colors**: Primary Emerald Accent `#00B47A`, Hover `#009b68`, Alert Amber `#F59E0B`.

- **Background & Surfaces**: Dark Mode Glassmorphism (`var(--color-surface)`), Border (`var(--color-border)`).

- **Typography**: Inter / Outfit modern geometric sans-serif font stack.



## 3. Component Standards

- **Dynamic Sidebar (`DynamicSidebar.tsx`)**: Re-orders navigation based on user role.

- **Universal Entity Header (`UniversalEntityHeader.tsx`)**: Renders project lifecycle stage, AI confidence, and primary action buttons.
